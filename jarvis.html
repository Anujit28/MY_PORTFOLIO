🤖 Jarvis — AI Voice Assistant

A personal voice assistant powered by Groq AI (LLaMA 3.1) and Python, built for hands-free interaction. Just say "Jarvis" and give your command — it listens, thinks, and talks back.

Demo

✨ Features

  • 🎙️ Wake-word activation — always listening for "Jarvis"
  • 🧠 AI-powered responses via Groq's ultra-fast LLaMA 3.1 8B model
  • 🔊 Text-to-speech output — every answer is spoken aloud
  • 🌐 Built-in shortcuts — open Google, YouTube, and JioHotstar instantly
  • 💬 Conversation memory — remembers context across the whole session
  • 🧹 Markdown-clean speech — strips formatting symbols before speaking

📦 Installation

1. Clone the repository

git clone https://github.com/anujit28/jarvis-voice-assistant.git
cd jarvis-voice-assistant

2. Install dependencies

pip install speechrecognition pyttsx3 groq pyaudio

Windows users: if pyaudio fails, install via wheel:

pip install pipwin
pipwin install pyaudio

Linux users:

sudo apt-get install python3-pyaudio portaudio19-dev

3. Add your Groq API key

Open PROJECT1.py and replace the placeholder:

GROQ_API_KEY = "your_groq_api_key_here"

Get a free key at console.groq.com

🚀 Usage

python PROJECT1.py

Jarvis will greet you. Then:

  • Say "Jarvis" to wake it up
  • Wait for the confirmation prompt
  • Speak your command

🗣️ Example Commands

"Jarvis, open Google"Opens google.com
"Jarvis, open YouTube"Opens youtube.com

"Jarvis, what is quantum computing?"AI explanation, spoken aloud

🔧 Configuration

You can tweak these settings at the top of PROJECT1.py:

GROQ_MODEL = "llama-3.1-8b-instant"   # Change AI model
recognizer.energy_threshold = 300      # Mic sensitivity (raise in noisy rooms)
_engine.setProperty("rate", 175)       # Speech speed (words per minute)
